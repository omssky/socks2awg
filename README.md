# socks2awg

[![Checks](https://github.com/omssky/socks2awg/actions/workflows/ci.yml/badge.svg)](https://github.com/omssky/socks2awg/actions/workflows/ci.yml)

Менеджер SOCKS5-прокси с выходом через AmneziaWG. Импортируйте AWG-конфиг и получите готовый SOCKS5-прокси с логином и паролем. Каждый профиль запускается в отдельном Docker-контейнере и использует свой порт.

```text
Клиент → SOCKS5 → AmneziaWG → Интернет
```

## Возможности

- Управление профилями через меню или команды.
- Импорт `.conf` из файла или вставкой в терминал.
- Автоматическое назначение портов и генерация паролей.
- Проверка подключения, просмотр логов и статистики.
- Автозапуск профилей после перезагрузки сервера.

## Требования

- Ubuntu или Debian с доступом root. Проверено на Ubuntu 24.04.
- AWG-конфиг с одним `[Interface]`, одним `[Peer]` и `0.0.0.0/0` в `AllowedIPs`.
- Доступный извне TCP-порт для каждого профиля. Домен не требуется.

## Установка

Выполните на сервере от root:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/omssky/socks2awg/master/install.sh)
```

Если Docker отсутствует, установщик предложит установить его через официальный скрипт [get.docker.com](https://get.docker.com). Требуется Docker Compose plugin; уже установленный Docker не заменяется. Установщик скачивает готовый образ wireproxy-awg из GHCR. Версия образа зафиксирована по digest; сборка на сервере не требуется.

После установки в терминале меню откроется автоматически. Для повторного запуска:

```bash
socks2awg
```

Укажите публичный IPv4 или домен сервера и выберите **«Добавить профиль»**. После импорта данные подключения доступны в карточке профиля.

## Добавление профиля

Чтобы вставить конфиг в терминал, выполните команду. После вставки оставьте две пустые строки подряд, нажав Enter дважды. Одна пустая строка внутри конфига допустима; завершение строкой `END` также поддерживается:

```bash
socks2awg add profile1
```

Для импорта файла сначала передайте его на сервер:

```bash
scp ./profile1.conf root@SERVER_IP:/root/profile1.conf
```

Затем выполните на сервере:

```bash
socks2awg add profile1 /root/profile1.conf
socks2awg show profile1
```

Порт и пароль создаются автоматически. Чтобы выбрать порт, добавьте `--port 11001`. После успешного импорта исходный файл можно удалить — его копия сохранена в профиле.

## Команды

| Команда | Описание |
| --- | --- |
| `socks2awg` | Открыть меню |
| `socks2awg add NAME [FILE] [--port N]` | Добавить профиль |
| `socks2awg list` | Показать профили |
| `socks2awg show NAME` | Показать адрес, пароль и SOCKS URL |
| `socks2awg check [NAME]` | Проверить один профиль или все и показать IP выхода |
| `socks2awg stats [NAME] [--watch]` | Показать CPU, RAM, трафик и время работы |
| `socks2awg logs NAME` | Показать последние 100 строк логов |
| `socks2awg start NAME` | Запустить профиль |
| `socks2awg stop NAME` | Остановить профиль |
| `socks2awg remove NAME [--yes]` | Удалить профиль; `--yes` отключает подтверждение |
| `socks2awg help` | Показать справку |
| `socks2awg version` | Показать версию |

## Обновление

Повторно запустите команду установки. Конфиги сохранятся, работающие профили продолжат работу. Обновление утилиты не заменяет ядро существующих профилей — для этого их нужно пересоздать.

Для замены настроек удалите профиль и добавьте его заново. При этом будет создан **новый SOCKS-пароль**; прежний порт можно указать через `--port`.

## Примечания

- Для каждого профиля нужен отдельный AWG-ключ. Формат `vpn://` не поддерживается.
- SOCKS-вход работает по IPv4/TCP. SOCKS5 не шифрует подключение и пароль; HTTPS-трафик остаётся защищён TLS.
- Откройте TCP-порт профиля в фаерволле сервера и хостера. Скрипт не изменяет настройки фаерволла и SSH.
- Если в конфиге нет `DNS`, используется `1.1.1.1` через туннель. Локальный UDP-порт AWG выбирается автоматически.
- `check` проверяет выход через `api.ipify.org`. Если проверка после добавления завершится ошибкой, профиль сохранится для диагностики.
- Счётчики трафика сбрасываются при перезапуске ядра. Конфиги и пароли хранятся в `/var/lib/socks2awg` с доступом только для root.
