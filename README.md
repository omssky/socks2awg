# socks2awg

Менеджер туннелей **SOCKS5 → AmneziaWG** с CLI и меню.
Каждый профиль — отдельный контейнер, SOCKS-порт, пароль и AWG-конфиг.

На основе [wireproxy](https://github.com/windtf/wireproxy).
Для поддержки AmneziaWG используется форк [wireproxy-awg](https://github.com/artem-russkikh/wireproxy-awg).

## Установка

Ubuntu / Debian, запуск от root. Проверено на Ubuntu 24.04.

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/omssky/socks2awg/master/install.sh)
socks2awg
```

Нужен Docker с Compose. Установщик предложит установить Docker, если его нет;
при первой установке соберёт образ ядра. При первом запуске меню укажите публичный
IPv4 или домен сервера для ссылок подключения. Домен не обязателен.

## Добавление профиля

Вставить содержимое `.conf` в терминал, завершив отдельной строкой `END`:

```bash
socks2awg add profile1
```

Или передать файл с компьютера:

```bash
scp ./profile1.conf root@SERVER_IP:/root/profile1.conf
```

Затем на сервере:

```bash
socks2awg add profile1 /root/profile1.conf
socks2awg show profile1
```

Порт и пароль создаются автоматически. Свой порт: `add profile1 ./profile1.conf --port 11001`.
После успешного импорта исходный файл можно удалить — утилита сохраняет копию.

## Команды

```text
socks2awg                            меню
socks2awg add NAME [FILE] [--port N]  добавить профиль
socks2awg list                       список профилей
socks2awg show NAME                  адрес, логин, пароль и SOCKS URL
socks2awg check [NAME]               проверить один профиль или все, показать IP выхода
socks2awg stats [NAME] [--watch]      CPU, RAM, трафик, время работы и handshake
socks2awg logs NAME                  последние 100 строк логов
socks2awg start NAME                 запустить
socks2awg stop NAME                  остановить
socks2awg remove NAME [--yes]         удалить; без --yes нужно подтверждение
socks2awg help                       справка
socks2awg version                    версия
```

## Конфиги и подключение

- Обычный AWG `.conf`: один `[Interface]`, один `[Peer]`, `AllowedIPs` включает `0.0.0.0/0`. Формат `vpn://` не поддерживается.
- Для каждого профиля нужен отдельный AWG-ключ; не используйте его одновременно в другом клиенте.
- Если `DNS` отсутствует, используется `1.1.1.1` через туннель. Локальный UDP-порт AWG выбирается автоматически.
- SOCKS-вход — IPv4/TCP с логином и паролем. Сам SOCKS5 не шифрует подключение, включая пароль; HTTPS остаётся защищён TLS.
- При закрытых входящих соединениях откройте TCP-порт профиля в фаерволле сервера/хостера. Утилита не настраивает фаерволл и SSH.
- `check` обращается к `api.ipify.org` через туннель. При сетевой ошибке после добавления профиль сохраняется для диагностики.
- Счётчики трафика сбрасываются при перезапуске ядра. Работающий контейнер не гарантирует доступность туннеля — используйте `check`.

## Обслуживание

Для замены настроек удалите профиль и добавьте заново. **SOCKS-пароль изменится**;
для сохранения номера порта укажите `--port`. Другие профили продолжат работать.

Обновление утилиты — повторный запуск установщика. Профили сохраняются,
работающие контейнеры не перезапускаются. Чтобы обновить ядро существующего профиля,
пересоздайте его после обновления утилиты.

Конфиги и пароли хранятся в `/var/lib/socks2awg` с доступом только для root.
Запущенные профили автоматически поднимаются после перезагрузки сервера.
